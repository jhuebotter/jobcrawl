# JobCrawl MVP

JobCrawl is a local-first, single-user web application for discovering and managing professional entities. It uses an agentic backend to automatically discover, structure, and present information about organizations, research labs, and companies relevant to your interests.

## Features

-   **Agentic Discovery**: Automatically finds and structures information from the web based on user-defined tags and locations.
-   **Local-First**: All data is stored and processed locally on your machine.
-   **Reactive UI**: A simple web interface for configuring runs, browsing data, and curating results.
-   **AI-Assisted Curation**: Manually add entities with minimal information and let the agent fill in the details.
